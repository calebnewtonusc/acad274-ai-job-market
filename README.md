# AI and the Job Market

ACAD 274 Group 1 (Fall 2026): Keanna, Mikayla, Jerry, Ellen, Caleb.

A data website that combines public datasets on jobs, wages and AI exposure in a
MySQL database, serves them as JSON feeds, and lets people explore how AI is
changing the job they want.
