
Designing and developing/Implementing full-stack, interactive data sites

This course has a very unique multi-domain approach to a topic that I have not seen at USC before, and honestly could only see the Academy trying. Like any Academy project it is iterative, and your feedback and input are important to help it evolve and improve for future cohorts.

As we look back on the design+tech+data journey we've taken, let's review some of the areas we have dipped into, which I honestly have never seen one course (especially with no prequisites) ever try to tackle in one semester. Now some of these had explicit learning units and some were only practice-based:

- (Low-level) data insights, informtion extraction, (to a lite extent) analyticsdatabase understanding. creating views. extracting/combining data.

- (Interactive) Data Visualization (lowish level)charting data. flowing data into chart plug-ins

- Interactive, front-end web pages and uxhtml, css, jQuery, interactive ux

- Back-end scripting (databases into web / mobile apps)

- Research

- User testing

Normally my courses focus first on literacy and fluency in technology, then build up skill/tech compentencies. This class was a bit flipped with often throwing code at you, explaining a bit how it works, then asking you to try implementing it... without having learned the building blocks/fundamentals first. From the units above:

- All should have some base-level literacy in all, but which do you feel you have more or less comprehension? What level of low- to medium-level compency (this will also vary a lot with which roles you took in the projects) in each area?

- What are some of the understandings and practical skills you feel you learned in each area?
	Front-end: build a page, add interactivity. html? css? flex? jquery?
	Db: understanding of structuing data? creating specific views/versions?
	json: what it is, why important, how can use. idea of feeding data to a front-end?
	back-end: (in our case with php) connecting to a db, getting out data

- What would next steps be to learn more in each area? Have you identified related courses? Are you moving on to any of them?

- Were there some units you wish we did more theory in? More code / implementation in?
