Milestone 3: Complete alpha build sites, live data visualizations, user testing
This penultimate build will feature your complete website, including cohesive design across all pages, and data visualizations that feature live (from db) data. It also includes user testing and working up a list of potential changes and additions, to implement in the final build.
The alpha build for Milestone 3 requires:

Complete website that has/includes the following features:

Frontpage: Strong statement of purpose/claim including distinct, original graphic elements.
Site/page content: Spread among your pages but organized as you see fit includes:

Uniform design and look and feel across the site. Some distinct site identity logo or nameplace would be a good addition.
Data grid/table output of core, relevant data. In most projects this will be at least 2 - 3 core datasets/outputs. These should not be raw data but rather from views that draw conclusions (normally aggregate statistics). Please
Interactive narratives: Placeholder page with (for now) a detailed scenario / walkthroughs of how you will interactively lead the user through an experience through detailed sequences, interactive highlighs/animations, etc. You can also choose to display the storyboards here (see below).
Visualizations of summary and conclusion data (see below)


Live data visualizations: Your data visualizations must pull data live from the database. For this build they do not have to have interactive elements.
User testing: Put premise and data visualizations in front of people, collect responses, create list of preposed changes, new approaches. These will be addressed/implemented in the final build.
Storyboards for a scripted or interactive narrative sequence: Plan out a sequence (potentially similar to the animated presentation lab) in which a user would be led through a series of timed and scripted out sequences. Then storyboard (can be hand-drawn) each step, including timings and notes or text and interactions. This scripted, narrative experience can be fulfilled in a number of ways:

Interactive walkthrough/tutorial of a major site element, including timings and delays, pop-up messages and explanations, and animations.
Scripted and narrated explanation of the site and topic, with animated elements (can be static screenshots of charts and output from pages), examples, etc. Very easy to record some mp3 audio clips and have them be triggered at certain points of the scripted/planned sequence.
Feel free to ask me/pitch other ideas to fulfill this requirement.

To fulfill this requirement you do need planned out, timed sequences, hence the storyboard planning first.

For planning purposes, please note below I have included some of the features from the requirements of the final build. You could start working on them early and include betas of versions in this alpha build:

Interactive data visualizations: Visualizations should have interactive elements which can include filters and user ability to adjust the data (to test scenarios).
Scripted visualization changes: Narrative sequences / options / buttons that allow the user to pick a pre-set option/scenario/data change and see the live update to the visualization.
Animated visualization changes: If your visualizations are a bit more on the standard/minimal side, such as traditional charts, then changes in data (from pre-written sequences or user interaction/changes) should be animated.

Link to a doc with Storyboards for a Final Build Narrative Sequence (can be hand-drawn)

Live data back-end (not from spreadsheets)
