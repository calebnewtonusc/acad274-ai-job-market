Animated presentation lab
For this you will put together a presentation web page that has 4 - 5 "slides", each of which has text AND some images. You CAN use the completed class demo as a framework and recycle its code as sample code.
Your page should be driven by a data-driven argument, in four to five steps. This CAN be a repurposing of content from any of your previous assignments.
Page requirement:


Adapt (from the demo) or design from scratch an original layout where only one of the "slides" appears as a time (again like the demo).
At least two slides should have significant graphic/image elements OR html tables.
Have a Next or Continue button at the top or bottom of each "slide".
Use the jQuery animate() method to create transitions between the slides
Vary the transition effects.

So you are welcome to use the complete class demo jquery_presentation2.html as a framework or starting point for your lab. If so, the first thing you should do is CHANGE/redesign the color scheme... and preferably tweak the layout divs a bit (to look less like the mobile-first demo).If you are going to use the demo as the framework for your page, you must also tweak/change the animations a bit, and those animate() transitions should be more than just an opacity change, but should tie in changes toother elements as well such as width and height, top and left (if you use absolute or relative positioning), font-size, etc.
