Lab: Set up your iyaserver web space, uploading an image
This quick lab consists of successfully logging into your web server space, setting up a new folder/directory named acad274 (in the proper locatin), and uploading an alternate image (or avatar) or yourself to that space.

Log into the web server portal location at https://webdev.iyaserver.com/cpanel.
Your course pw is three pieces of information with underscores in between them:

AcadDev
Lastname (capital first letter). This is the lastname that USC has listed for you in its systems (registration, etc.)
USC Student ID number

So for instance mine might be AcadDev_Dent_9998887777

Your server username is your USC userID, i.e. the portion of your usc email before @usc.edu. So for instance my usc email is dent@usc.edu so my ID is dent. This would also be the "userID" you use to log into most USC systems.
Your password is a SPECIFIC mask that is the string AcadDev + underscore character + your Lastname (capital first letter) + underscore + your USC Student ID. So for instance mine might be AcadDev_Dent_9997775555.


Inside cPanel, go to Files > File Manager
Select/open the public_html folder then at the top of the screenclick on the + Folder button, and title the new folder acad274. To test if this worked go to the Roster resource and click on the test "root" link, and you should see your newly created acad274 folder there.
Open up the folder.
On your computer, find an alternate image or avatar for yourself. RENAME the file to avatar.jpg (note if it is not a jpg you may need to convert it).
Drag or upload the avatar.jpg file into the acad274 folder in your publichtml web space. If you open up both folders (webpage and Finder/File Explorer) you can drag it up or with the acad274 folder open in the cPanel webpage you can click on the Upload button.

 
To submit the completed lab, either paste the direct URL to your avatar.jpg file OFF THE WEB (from the public server), which is the preferred method as that will make sure you understand the direct URL to your uploaded image. OR, you can re-paste the student roster url that you have verified is successfully displaying your avatar image. Finding the avatar url: On the classpage if you click on your root link, then click open (in the web browser) your acad274 folder, then click on avatar.url... not only will the image display directly, but you can then copy that URL and submit it to the Brightspace lab.
 
Testing that the lab completion:
To see if this worked open up the https://iyawebdev.com/acad274/20263_students.html, also located in Brightspace under Content > Resources > Student server links/roster, and you should automagically see the avatar you uploaded next to your USC photo.
